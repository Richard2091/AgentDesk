# 控制层文档

状态：第二阶段最小运行闭环已完成；策略、审计、人工确认和外部入口仍属于后续阶段。

职责：管理会话、统一请求、策略、确认、调度和审计。

权威文档：[架构总览](../global/architecture/architecture.md)、[消息协议](../global/contracts/protocol.md)、[安全设计](../global/security/security.md)。

当前实现：`control_layer/main.py` 建立单 Executor 会话绑定，发送认证能力查询、执行、状态和取消消息，并统一返回能力报告、终态结果和结构化错误。服务当前以内存运行时调用 Executor 消息服务；真实标准输入输出链路由 Executor 集成测试覆盖。

已验证：成功执行、参数错误、权限拒绝、未知工具、请求幂等与冲突、超时、取消、内部异常、重放和未知字段。控制层不绕过 Executor 的信封验证、工具参数校验或结果校验。

安全边界：当前会话认证使用开发期本机 HMAC-SHA256，共享密钥来自环境变量；不宣称生产级密钥管理、Ed25519、持久化恢复、审计存储或远程 RustDesk 接入已完成。
