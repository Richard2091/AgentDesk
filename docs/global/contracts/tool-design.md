# 工具目录与能力契约

状态：设计草案，未冻结、未实现。本页只维护工具声明；调用消息、状态及错误仅定义在[消息协议](protocol.md)，安全策略见[安全设计](../security/security.md)。

## 工具声明字段

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| `name` | 字符串 | 是 | 全局唯一名称，按命名空间注册 |
| `version` | 字符串 | 是 | 工具契约版本，与消息协议版本分离 |
| `description` | 字符串 | 是 | 面向使用者的中文能力说明 |
| `input_schema`、`output_schema` | 对象 | 是 | 参数及成功结果的 JSON Schema；草案冻结时固定方言 |
| `executor` | 字符串 | 是 | 实现类型，不是目标设备编号 |
| `risk_level` | 枚举 | 是 | `low`、`medium`、`high`；分级规则仅见安全设计 |
| `permissions` | 对象 | 是 | 工具、资源、动作范围及约束；不得用能力报告替代授权 |
| `side_effects` | 枚举 | 是 | `none`、`local_write`、`external_write` |
| `default_timeout_ms`、`max_timeout_ms` | 正整数 | 是 | 默认值不得大于上限；运行超时口径见协议 |
| `cancellation` | 对象 | 是 | 支持阶段、停止方式、无法中断的区段及清理要求 |
| `audit` | 对象 | 是 | 记录摘要、脱敏规则、结果敏感性和审计失败处置 |
| `errors` | 数组 | 是 | 本工具可能返回的协议错误码及触发条件 |
| `validation_cases` | 数组 | 是 | 正常、边界、拒绝、超时、取消、重复请求的验收用例 |

声明未知权限、缺字段、名称重复或版本不支持时拒绝注册；不能通过默认值静默扩大权限。单次请求不得放宽声明中的资源限制。

## 首个工具的候选设计

拟先实现 `windows.system.info`：读取系统版本和执行器版本，暂不返回用户名、主机名或进程列表。候选实现类型为 `windows`，副作用为 `none`，默认低风险仍需读取权限。该候选不是已注册工具。

输入拟为空对象并拒绝多余字段，成功结果拟包含 `os_version` 和 `executor_version` 两个字符串。数值超时、权限标识、取消清理方式和字段 Schema 尚待技术基线实验确认；未补齐上表全部字段及用例前，不能宣称工具可用。

## 发现与调用

能力报告携带完整工具声明与能力版本。调用使用工具名和契约版本，目标设备由外层信封的 `executor_id` 指定。控制层按[协议的能力发现规则](protocol.md#能力发现)校验最新声明，执行器仍需独立校验权限。

新增工具应同时提交上述完整声明、模块特有边界、可复现演示及[验证计划](../progress/validation-plan.md)中的适用用例。未实现能力不加入可用列表。
