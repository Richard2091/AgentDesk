# ADR-001：第一阶段协议安全参数边界

状态：已批准（第一阶段冻结基线）
日期：2026-09-12

## 背景

消息协议已具备信封、载荷、错误和能力报告模式，但安全参数尚未完成决策，直接冻结会导致控制层与 Executor 无法一致实现。

## 当前决策边界

- 编码统一使用 UTF-8 JSON，拒绝重复键、未知字段和缺少必填字段。
- 请求查询必须显式携带目标请求编号，并按会话、执行器和调用身份过滤可见性。
- 取消状态进入 `cancelling` 后，只有清理完成或明确无法继续时才能进入终态。
- 超时、内部错误和审计不可用不得自动重新执行副作用请求；只允许查询或人工重新评估。

## 正式决策

- 签名：Ed25519；签名输入采用 UTF-8、确定性 JSON 序列化，拒绝重复键。
- 时间：消息最大有效期 60 秒，允许时钟偏差 30 秒；最大信封 256 KiB。
- 随机数：每条消息至少 128 bit，并按会话保留至过期后 5 分钟。
- 业务指纹：规范化工具名、契约版本、参数和超时后使用 SHA-256。
- 确认令牌：绑定请求、会话、执行器、工具、参数摘要和审批者，单次消费，最长 5 分钟。
- 崩溃恢复：副作用结果未知时禁止自动重放，必须查询并转人工核对。

以上参数作为第一阶段冻结基线；后续变更必须新增 ADR 并更新协议版本。
