# 验收与验证计划

本页是验证场景和证据要求，当前无运行实现。除文档静态检查另见[整改记录](documentation-remediation.md)外，以下所有业务测试均未执行。

## 分阶段验收矩阵

| 标识 | 阶段 | 场景 | 通过条件 |
|---|---|---|---|
| 基线 | 第零阶段 | 干净环境构建、启动、停止控制层及 Executor | 依赖版本、配置与命令可复现，退出无遗留资源 |
| 契约 | 第一阶段 | 全部消息/工具 Schema 的正反例 | 缺字段、未知字段/消息、错误版本、非法时间与超大载荷被拒绝 |
| 身份 | 第一、二阶段 | 伪造调用者/签名者、跨会话、过期消息 | 不执行、不泄露其他请求状态，有脱敏拒绝记录 |
| 幂等 | 第二阶段 | 同消息重放、同请求新消息、同编号改参数 | 分别拒绝重放、只返回原状态、返回内容冲突，不重复执行 |
| 只读 | 第三阶段 | 系统查询、截图、窗口目标不存在/权限变化 | 按权限返回结构化结果或拒绝，敏感数据不进入普通日志 |
| 审计 | 第四阶段 | 审计失败、身份关联、秘密参数 | 新副作用被阻止，紧急停止不受阻，脱敏有效且缺口可追溯 |
| 确认 | 第五阶段 | 批准、拒绝、过期、冒充审批、令牌重复/参数变化 | 仅有效且有权限的决定可触发一次执行 |
| 竞态 | 第五阶段 | 确认与取消、令牌消费与崩溃 | 状态单向提交，未知副作用不自动重放 |
| 入口 | 第六阶段 | MCP 身份、进度、错误、取消及客户端断开映射 | 与统一内部调用一致，不绕过策略，不误报取消成功 |
| 接管 | 第七阶段 | 执行前/中接管、无法取消、断连、恢复 | 双端冻结，不使用过期画面/确认续跑，未停止动作可见 |
| 写入 | 第八阶段 | 路径穿越、重解析点、目标替换、剪贴板敏感内容 | 越界拒绝，局部失败可追踪，清理不误删原数据 |
| 执行 | 第九阶段 | 非法脚本参数、进程编号复用、输入焦点变化 | 对错误目标不执行，超时、取消和按键清理有证据 |
| 扩展 | 第十阶段 | UI 自动化及前序能力跨工具回归 | 使用完整声明和最新权限，已实现能力无语义分叉 |
| 运维 | 第十一阶段 | 多入口/执行器、版本升级、背压、恢复演练 | 隔离有效、容量边界明确、审计可查且回滚条件可复现 |

各阶段补充其工具声明中的错误、超时、取消和审计用例；不要求尚未实现的功能产生虚假的测试报告。

## 证据格式与执行边界

每项记录环境、版本、命令、输入摘要、期望值、实际输出、证据路径、结论和风险。状态只能为未执行、通过、失败或不适用；不适用需说明原因。

先执行本地模式与模拟依赖测试。真实远端、生产数据及外部服务验证需明确授权和回滚方案。代码与依赖缺失时只做文档、链接和契约语义检查，不将其计为功能或安全测试通过。

## 发布与恢复

所有实现阶段必须提供与交付物匹配的可运行产物：第一阶段至少包括 Schema 校验脚本及固定样例，第二阶段起包括组件运行与端到端演示。接管、权限、确认、重放和取消门禁不通过时不得开放相应副作用能力。

回滚验证需核对协议兼容、未完成请求、已消费令牌和审计记录，不能通过恢复旧状态导致重复执行。运行回滚机制目前未实现。
