# 适配器模型

状态：规划，未实施。整体拓扑以[架构总览](architecture.md)为准，本页仅定义适配层扩展点。

| 类型 | 输入与输出 | 模块负责的转换 |
|---|---|---|
| 入口适配器 | 客户端调用 → 控制层内部调用 | 认证凭据映射、调用关联、错误/进度/取消映射 |
| 会话适配器 | 统一业务消息 ↔ 绑定的执行器会话 | 封装、收发、断连报告、流量与连接管理 |
| 工具实现适配 | 已验证工具参数 → 本地系统调用 | 参数映射、系统错误归一化、局部资源清理 |

入口适配器接收的客户端调用不是可直接转发给 Executor 的签名信封；控制层在认证和策略检查后构造业务消息。Codex CLI 是控制端客户端，不能固定放在控制层与远程 Executor 之间作为传输节点。控制端 Playwright 或自定义工具注册属于后续扩展，尚无独立执行路径。

首期入口映射见[MCP 模块](../../mcp-adapter/README.md)，会话复用及扩展点见[RustDesk 模块](../../rustdesk-session/README.md)，消息模式见[协议](../contracts/protocol.md)。连接失败只报告状态，适配器不自行重放执行消息；重试判断交给协议及安全策略。
